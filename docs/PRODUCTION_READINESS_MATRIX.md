# Inventory Management System (IMS) — Formal Production Readiness & Acceptance Matrix

> **Production Readiness Definition**: Correct under failure, secure under attack, recoverable after disaster, observable in operation, and deployable repeatedly without corrupting operational inventory or financial data.

---

### Action Plan for 100% Launch Clearance:
1. **PostgreSQL & Alembic Migration Baseline**: Transition local dev SQLite default to PostgreSQL instance managed via Alembic versioning.
2. **Password Hashing Standard**: Upgrade password KDF from PBKDF2 to Argon2id/bcrypt standard via `passlib`.
